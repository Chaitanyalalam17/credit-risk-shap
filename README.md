# Credit Risk Classification Using SHAP

## UCI German Credit Dataset | MSc Dissertation | Sheffield Hallam

## Research Question
To what extent can an ensemble ML pipeline, enhanced with 
SHAP-based explainability, improve both prediction accuracy 
and stakeholder trust in classifying credit risk in banking 
loan applications?

## Project Structure
- notebooks/ — Jupyter notebooks for each stage
- data/raw/ — Raw dataset (not pushed to GitHub)
- data/processed/ — Cleaned data
- models/ — Saved trained models
- shap_plots/ — SHAP visualisations
- reports/ — Dissertation outputs
- references/ — Paper PDFs

## Models Used
- XGBoost
- LightGBM
- Random Forest
- Logistic Regression (baseline)

## Explainability
SHAP (SHapley Additive exPlanations) — Lundberg & Lee (2017)
